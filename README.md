Politique de confidentialité – QR Dess Code DOC

La présente politique de confidentialité explique comment la solution QR Dess Code DOC, composée des logiciels QR Dess Code PRO et QR Dess Code Generator, utilise les autorisations et les données de votre appareil pour fournir ses fonctionnalités. En utilisant la solution, vous acceptez les pratiques décrites ci-dessous.

1. Données et accès utilisés

Accès à la caméra (QR Dess Code PRO)
La caméra est utilisée uniquement pour lire des QR Codes. Les images sont traitées en temps réel sur votre appareil et ne sont ni enregistrées ni transmises.

Accès aux fichiers locaux

QR Dess Code PRO lit les images et les fichiers CSV que vous sélectionnez, et enregistre les planches de QR Codes (PDF) à l’emplacement de votre choix.
QR Dess Code Generator lit l’arborescence de documents que vous désignez sur votre ordinateur afin de la charger dans votre instance NextCloud.

Paramètres de connexion NextCloud (QR Dess Code Generator)
L’adresse de votre serveur NextCloud, votre identifiant et votre mot de passe (ou jeton d’application) sont enregistrés uniquement sur votre appareil. Ils ne sont jamais transmis à l’éditeur.

Abonnement
L’abonnement est géré par le Microsoft Store. La solution interroge le Microsoft Store pour vérifier qu’un abonnement est actif sur votre compte Microsoft. Le paiement est traité exclusivement par Microsoft : l’éditeur n’a accès à aucune donnée bancaire.

2. Utilisation des données

Les données ci-dessus servent uniquement au fonctionnement de la solution. Aucune donnée personnelle n’est collectée par l’éditeur ni utilisée à d’autres fins. La solution ne contient aucune publicité et n’utilise aucun service d’analyse ou de suivi.

3. Transmission et partage des données
Les seules données transmises sont les documents et informations que vous choisissez d’envoyer, via QR Dess Code Generator, vers votre propre instance NextCloud.
NextCloud est un logiciel tiers qui ne fait pas partie de la solution. Son hébergement, sa sécurité et le traitement des documents qui y sont stockés relèvent de votre responsabilité et, le cas échéant, de votre hébergeur.
L’éditeur n’a accès ni à votre instance NextCloud, ni à vos documents, ni à vos identifiants.
Aucune donnée n’est partagée avec des tiers.
4. Sécurité

Les données de la solution restent sur votre appareil, à l’exception des documents chargés sur votre instance NextCloud. Nous recommandons d’utiliser une connexion HTTPS vers votre serveur NextCloud et de protéger par mot de passe les liens de partage contenant des documents confidentiels.

5. Droits des utilisateurs

L’éditeur ne collectant aucune donnée personnelle, il n’en détient aucune à supprimer. Les documents chargés sur NextCloud restent sous votre contrôle : vous pouvez les modifier ou les supprimer à tout moment depuis votre instance. Si ces documents contiennent des données personnelles de tiers, vous êtes responsable de leur traitement au regard du RGPD.
Vous pouvez révoquer l’accès à la caméra à tout moment dans les paramètres de Windows (Confidentialité et sécurité > Caméra).

6. Modifications de la politique

Nous pouvons mettre à jour cette politique à tout moment. Les modifications seront publiées sur cette page avec la date de mise à jour.
